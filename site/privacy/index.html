Privacy

Sandbox Capacity Probe is local first. The CLI sends no telemetry.

It does not send probe results, runtime details, container names, or host details to Sociobot.

Website storage

The free planner does not require an account. Demo changes use a separate browser-storage key and are discarded when you exit.

Planner Pro stores its license, last verification result, and saved scenarios in this browser. Clear site data to remove them.

License verification

The site sends your license token to Sociobot when verification is due. Automatic checks occur at most once each day.

This browser allows one manual verification attempt each minute.

Offline use and logs

A service worker stores the public site files for offline reading. There are no advertising cookies, behavioral analytics, or third-party scripts.

Infrastructure logs may temporarily record an IP address, request path, browser name, and timestamp for security.

Contact

Email privacy@sociobot.in for privacy requests. Include “Sandbox Capacity Probe” in the subject.
