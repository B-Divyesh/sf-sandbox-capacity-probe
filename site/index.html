How it works / 02

How the capacity probe measures a host

The probe turns a planned workload into host-specific evidence. Every result names the runtime, context, image, workload, and limits.

STEP / A

Measure container startup time

Start containers at four levels. Measure startup time as local port bindings and mounts increase.

STEP / B

Compare startup time with your budget

Calculate the p95 startup time. Label the planned workload comfortable, watch, or exceeded.

STEP / C

Compare two probe reports

Repeat the planned workload later. capacity-probe compare reports prediction error against the 25% target.

Safe probe steps / 03

How a probe contains test containers

  1. Name and confirm the target.Production-like names are refused unless separately overridden.
  2. Review a dry run.See the maximum starts, ports, mounts, and measurement levels without runtime access.
  3. Measure and compare.Save JSON, repeat under controlled load, and quantify prediction accuracy.
staging-west / surveycapacity-probe 0.1.0
$ cargo install --path cli
$ capacity-probe probe \
  --target staging-west \
  --confirm staging-west \
  --containers 12 \
  --ports-per-container 2 \
  --mounts 1 \
  --samples 3 \
  --output capacity.json
